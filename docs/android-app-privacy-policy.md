# Smart Drink Fridge Android App — Privacy Policy

_Last updated: October 20, 2026_

The Smart Drink Fridge Android app connects directly to a Smart Drink Fridge server selected and operated by the user. The developer does not receive, collect, store, sell or share personal data, credentials, inventory information, booking data, analytics or advertising identifiers from the app.

The app stores the configured server address and an authentication token locally. The authentication token is protected using Android Keystore-backed encryption. Cached website data remains in Android WebView storage on the device. Users can remove local data through Android's app-storage controls or by uninstalling the app. Data on the selected Smart Drink Fridge server is controlled by that server's operator.

Camera access is optional and used only to recognise drink barcodes. Camera frames are processed on the device and are not uploaded or retained by the app.

The app contains no advertising SDK, analytics SDK or cross-app tracking. Demo mode uses synthetic local sample data and makes no server connection.

For privacy questions, open an issue or discussion at https://github.com/DerRobin99/smart-drink-fridge.
